**Noctis Plus 2.7.1**: songs still downloading play again.

## Fixed

- A streamed song whose download was still running (for example one resumed after the internet came back) was treated as a missing file and skipped. Skipping stopped its download, so a For you page or a playlist could skip song after song. Such songs now play from their download as before.

## Install or update

Existing installations can update through Noctis Plus. For a new installation, paste into PowerShell:

```powershell
irm https://raw.githubusercontent.com/Alfamin/NoctisPlus/main/scripts/install.ps1 | iex
```

Downloads: `NoctisPlus-v2.7.1-Setup.exe`, `NoctisPlus-windows-x64.zip` and `SHA256SUMS`.
