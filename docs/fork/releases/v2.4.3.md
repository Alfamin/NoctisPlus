**Noctis Plus 2.4.3**: a smoother first run, lighter word timing and quick quality switches.

## What's new

- **Word timing uses half the memory.** WordLyrics now sends its voice model one piece of a song at a time. One song used to need about 12 GB, which on an 8 GB graphics card spilled into system memory and stalled; now it needs about 5 GB, at the same speed and with the same lyric files. Existing WordLyrics installs get this through the Noctis update.
- **MP3 or FLAC switches in seconds.** Changing the download quality no longer waits for downloads already running, and both bots are set at the same time.

## Fixed

- Home no longer draws the welcome card over Continue listening and Last Played when you've only streamed songs; Last Played takes the full row.
- Statistics and Wrap count each streamed song's real length instead of 3:30.
- Unsaved playlists opened from Search play in source order with their missing songs, replacing the old queue.
- Saving the current For you song hides Not for me beside its lyrics.
- Before WordLyrics is set up, its panel only offers Set up WordLyrics.
- Opening Settings closes the sidebar search box instead of drawing under it.
- Telegram sign-in has an Open button for the API page, and the playlist import no longer repeats the same reason under every missing song.

## Validation

Application suite: zero failures. Finder: 1,660 checks, zero failures. Real-app checks on the TEST profile and on fresh first-run profiles: word timing peaked at 4.8 GB for a streamed song (was 12+ GB); both bots confirmed a quality change about 4.5 and 8.5 seconds after picking it, in both directions, while downloads ran; Home on an empty library after two streams at wide and narrow sizes and after a restart; Statistics after streamed plays.

## Install or update

Existing Noctis Plus installations can update through the app. For a new installation, paste into PowerShell:

```powershell
irm https://raw.githubusercontent.com/Alfamin/NoctisPlus/main/scripts/install.ps1 | iex
```

Downloads: `NoctisPlus-v2.4.3-Setup.exe`, `NoctisPlus-windows-x64.zip` and `SHA256SUMS`.
