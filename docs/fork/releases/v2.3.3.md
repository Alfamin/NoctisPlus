**Noctis Plus 2.3.3** — the queue scrolls while you drag.

## What's new

- **The queue scrolls as you drag.** Hold a song near the top or bottom edge of the queue and the list scrolls by itself, faster the closer you get to the edge, so you can move a song far without scrolling by hand.

## Validation

Local validation: 6,786 application tests, zero failures; Finder: 1,580 checks, zero failures. Live check: in an 80-song queue, a song held at the bottom edge scrolled the list about 40 songs and dropped where it was released.

## Install or update

Existing Noctis Plus installations can update through the app. For a new installation, paste into PowerShell:

```powershell
irm https://raw.githubusercontent.com/Alfamin/NoctisPlus/main/scripts/install.ps1 | iex
```

Downloads: `NoctisPlus-v2.3.3-Setup.exe`, `NoctisPlus-windows-x64.zip` and `SHA256SUMS`.
