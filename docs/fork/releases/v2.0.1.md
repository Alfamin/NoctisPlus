**Noctis Plus 2.0.1.** Faster, more reliable downloads, and you can see what a download is doing.

## Install

Paste this into PowerShell (no administrator needed):

```powershell
irm https://raw.githubusercontent.com/Alfamin/NoctisPlus/main/scripts/install.ps1 | iex
```

Already on 2.0.0 or 1.6.3.x? Noctis Plus offers this update by itself. The Setup is not code-signed, so Windows SmartScreen may warn the first time: **More info > Run anyway**.

## What's new

- **See what a download is doing.** A small icon in the ring: a magnifier while the bot is asked, sync arrows when the other bot is tried, an arrow while the file arrives, a disk while it saves. It shows on the song you clicked, in the player's Play button, on For you covers and on the Downloads page. No more "Buffering…" line.
- **No more stuck downloads.** The bot's result is pressed half a second after its list arrives, pressed again if no file comes, and after 10 seconds without the file the other bot is asked. A song used to wait up to three minutes.
- **Imported playlist songs with several artists download now.** Spotify writes those names with a hidden special space; the bots found nothing for them. Searches to the bots now use plain text and the main artist.
- **Accents don't matter in Search.** "rosalia despecha" finds ROSALÍA's DESPECHÁ, not a karaoke cover.
- When a bot offers nothing that fits, the log lists what it did offer, so a missing song can be explained.

## Files

- `NoctisPlus-v2.0.1-Setup.exe`: the installer.
- `NoctisPlus-windows-x64.zip`: portable copy; extract to a new folder and run `Noctis.exe`.
- `SHA256SUMS`: checksums for both.
