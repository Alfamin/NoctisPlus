**Noctis Plus 2.7.3**: word-by-word lyrics fill again when word timing finishes during the song.

## Fixed

- When word timing for the song playing finished while it played (WordLyrics, often on a song just streamed), the lyrics went on line by line but the main lines no longer filled word by word; only the background vocals did. Opening the song again fixed it. The main lines now take the word timing at once.

## Install or update

Existing installations can update through Noctis Plus. For a new installation, paste into PowerShell:

```powershell
irm https://raw.githubusercontent.com/Alfamin/NoctisPlus/main/scripts/install.ps1 | iex
```

Downloads: `NoctisPlus-v2.7.3-Setup.exe`, `NoctisPlus-windows-x64.zip` and `SHA256SUMS`.
