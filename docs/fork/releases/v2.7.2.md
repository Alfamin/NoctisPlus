**Noctis Plus 2.7.2**: downloads recover from a network drop by themselves.

## Fixed

- After a VPN or network drop, the Telegram connection could stay broken. Every download and every song the For you page queued then failed, and Downloads showed "BadMsgNotification 48". The broken connection is now replaced, and the song tries again a few seconds later.
- A song a bot had already sent was asked for again when taking it from the bot's chat hit a connection error, and Retry failed did the same. The file is now always taken from the chat; no bot is asked for it again.
- While offline, playing from For you no longer starts and stops one download for every song on the page.
- Shuffle keeps songs that are still downloading instead of dropping them as missing.

## Install or update

Existing installations can update through Noctis Plus. For a new installation, paste into PowerShell:

```powershell
irm https://raw.githubusercontent.com/Alfamin/NoctisPlus/main/scripts/install.ps1 | iex
```

Downloads: `NoctisPlus-v2.7.2-Setup.exe`, `NoctisPlus-windows-x64.zip` and `SHA256SUMS`.
