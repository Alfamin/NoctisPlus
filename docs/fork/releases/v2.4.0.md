**Noctis Plus 2.4.0** — search by lyrics, faster album downloads.

## What's new

- **Search by lyrics.** Type a line you remember (at least four words, typos are fine) and the song it comes from leads the results, marked Lyrics. Song and album names, with or without the artist, "by" or "lyrics", still search by name.
- **Albums download faster.** While one song's file is arriving, the queue already asks for the next two, so long downloads run back to back.
- **Shuffle starts at once.** The first shuffle after opening the app no longer waits while every song in the library is opened.

## Fixed

- A download that stops moving for five minutes is restarted by itself, with a fresh Telegram connection, instead of holding up the whole queue.
- A short Telegram limit is read with its real wait; it used to stop both bots for a day.
- Several songs downloading at once each get their file from Music Hunters, instead of some falling back to DeezLoad.
- Word timing moves on past a song that fails or crashes it, and a lyric site that keeps refusing no longer makes songs loop; network errors wait at most an hour between tries.

## Validation

Local validation: 6,792 application tests, zero failures; Finder: 1,636 checks, zero failures. Live checks: lyric search found Drake, Queen, Olivia Rodrigo, Adele and Lil Nas X from lines of their songs; with every Telegram connection frozen mid-download, an album still finished from Music Hunters; reading song identities for a 2,138-song library took 0.03 s instead of about 9 s.

## Install or update

Existing Noctis Plus installations can update through the app. For a new installation, paste into PowerShell:

```powershell
irm https://raw.githubusercontent.com/Alfamin/NoctisPlus/main/scripts/install.ps1 | iex
```

Downloads: `NoctisPlus-v2.4.0-Setup.exe`, `NoctisPlus-windows-x64.zip` and `SHA256SUMS`.
