The first Noctis Plus release: Noctis 1.6.3 with Free Music Finder, True Shuffle, WordLyrics and Lyric Motion built in, an installer, and your Noctis profile brought over automatically.

## Install

Paste this into PowerShell (no administrator needed):

```powershell
irm https://raw.githubusercontent.com/Alfamin/NoctisPlus/main/scripts/install.ps1 | iex
```

It downloads `NoctisPlus-v1.6.3.1-Setup.exe` from this release through your system proxy/VPN, checks it against `SHA256SUMS`, installs it for your user and starts it. Or download the Setup below and run it yourself. The Setup is not code-signed, so Windows SmartScreen may warn the first time: **More info > Run anyway**.

Noctis Plus installs next to official Noctis (`%LOCALAPPDATA%\Programs\Noctis Plus`, data in `%APPDATA%\Noctis Plus`) and never changes, updates or removes it.

## What's in it

- **Four features built in, on from the start:** Free Music Finder 2.11.1, True Shuffle 1.5.0, WordLyrics plugin 1.2.4 and Lyric Motion 1.4.3. Each has its own switch and settings under Settings > Plugins. WordLyrics' Python program and models still install through its own setup.
- **Your Noctis profile comes over by itself.** The first start copies your whole official Noctis profile: library, play counts, ratings, history and the yearly wrap, playlists and queue, artwork and caches, plugin data and sign-ins (Last.fm, Finder's Telegram session). Official Noctis is only read. If it is open, Plus waits until you close it. An interrupted copy resumes on the next start.
- **Last.fm stays signed in** through network timeouts and rate limits; only a real "session expired" answer from Last.fm signs you out.
- **Its own updates:** Plus updates only from this repository's releases, verified with `SHA256SUMS`.

Don't run official Noctis and Noctis Plus at the same time: both use the same Telegram session, which can sign both out, and both would scrobble to Last.fm.

## Files

- `NoctisPlus-v1.6.3.1-Setup.exe`: the installer.
- `NoctisPlus-windows-x64.zip`: portable copy; extract to a new folder and run `Noctis.exe`.
- `SHA256SUMS`: checksums for both.
