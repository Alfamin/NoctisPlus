**Noctis Plus 2.6.1**: Better recovery when the music bots are busy.

## Fixed

- Music Hunters no longer waits two minutes for a completion notice that may never arrive. Recovery uses short, cancellable waits and a limited number of requests before pausing for another attempt.
- A busy Music Hunters with an already queued or temporarily unavailable reserve keeps the selected song waiting, rather than treating the recording as missing.
- DeezLoad's reported queue position appears in the download status while Music Hunters is retried.
- A matching file arriving during the wait, or after an earlier queue notice in the same response, is used without another request.

The bots' own queues can still delay delivery. The separate report of a For You selection appearing several places down the playback queue remains under investigation.

## Validation

Application suite: 7,997 tests, zero failures (54 skipped). Finder: 1,743 checks, zero failures. Real-app busy-bot and For You playback verification remains pending; desktop capture failed, so these results are automated checks, not a live reproduction claim. Release packaging and installation are checked by CI before publication.

## Install or update

Existing installations can update through Noctis Plus. For a new installation, paste into PowerShell:

```powershell
irm https://raw.githubusercontent.com/Alfamin/NoctisPlus/main/scripts/install.ps1 | iex
```

Downloads: `NoctisPlus-v2.6.1-Setup.exe`, `NoctisPlus-windows-x64.zip` and `SHA256SUMS`.
