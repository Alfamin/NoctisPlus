**Noctis Plus 2.2.0** — streaming, offline listening and better lyric controls.

## What's new

- **Play songs you don't have.** Imported playlists, albums and artist pages can stream missing songs in queue order, including True Shuffle modes. Configure this in Settings > Playback.
- **A focused listening queue.** Only the current song and next two positions fetch audio; bot lookups cover the next four positions, including songs already owned or cached. Skipped partial downloads stay in the cache for later reuse; explicit downloads keep their place.
- **Play just streams.** Played songs stay in a cache. Choose **Add to songs** or **Download** to keep them. Cache retention is configurable.
- **Remembered bot files.** Files the bots previously supplied are indexed locally, avoiding repeated requests. Choose the first bot in Settings; Music Hunters is the default.
- **Offline mode.** Keep listening to local music while online work waits. Interrupted streams wait instead of replaying their downloaded prefix; transfers retain partial progress.
- **Word timing as you listen.** Once set up, WordLyrics can time complete downloads for the current song and the next two, with the current song first. Model downloads still require consent.
- **Fewer lyric retries.** Missing or unsuccessful lyrics wait ten days before another automatic attempt. Ignore a song from its Lyrics menu; explicitly choosing **Time words** enables it again and prioritizes the request.
- **What's new, anytime.** Reopen these notes in Settings > About. Setting shortcuts in the app's notes take you directly to their controls.

## Fixed

- Album tracklists remain available when a library scan prevents ownership matching. Incomplete saved artist catalogs get an exact release lookup; failed album loads offer **Retry**.
- The player and lyrics-page menus include the same song lyric actions as Songs.
- WordLyrics' embedded panel uses one rounded backdrop; the Offline setting has no extra divider.
- Existing word timing is retained while updated timing is applied, and obsolete automatic queued notices are suppressed.
- Covers populate older imported playlists and the queue. Long titles truncated by Telegram can download again.
- Songs credited to several artists contribute to the correct recommendations. The player adapts to narrower windows.

## Validation and remaining checks

Local validation: 6,731 application tests, zero failures (43 skipped); Finder: 1,549 checks, zero failures. Extended real-world VPN interruptions and some new UI interactions still need user feedback. The latest reported blank-album case has automated regression coverage but has not yet been confirmed fixed in the owner's test app. No claim that every network or timing issue is resolved.

## Install or update

Existing Noctis Plus installations can update through the app. For a new installation, paste into PowerShell:

```powershell
irm https://raw.githubusercontent.com/Alfamin/NoctisPlus/main/scripts/install.ps1 | iex
```

Downloads: `NoctisPlus-v2.2.0-Setup.exe`, `NoctisPlus-windows-x64.zip` and `SHA256SUMS`.
